# Code of Conduct

## Our pledge

We want participation in this project to be respectful for everyone, regardless of age, body size, disability, ethnicity, sex characteristics, gender identity and expression, level of experience, education, socio-economic status, nationality, personal appearance, race, religion, or sexual identity and orientation.

## Expected behavior

- Be respectful and constructive in issues, reviews, and discussions.
- Give feedback on the code and the behavior, and keep it specific.
- Accept correction, and assume other people are acting in good faith.
- Respect private security reports. Follow [SECURITY.md](SECURITY.md).
- Use synthetic credentials and public DIDs in examples. Do not post real private keys or someone else's credentials.

## Unacceptable behavior

- Harassment, insults, or personal attacks
- Publishing another person's private information without permission
- Sexualized language or imagery, or unwelcome sexual attention
- Trolling, deliberate intimidation, or sustained disruption
- Sharing exploit details for an unfixed vulnerability in public

## Enforcement

Maintainers may remove comments, close issues or pull requests, and block further participation when this code of conduct is broken. Project decisions about verification behavior stay with the maintainers.

Report conduct concerns privately to the maintainers. If the repository is on GitHub, contact them through the address published on the repository profile, or through a private security advisory when the concern also involves a vulnerability. Do not post the report in a public issue.
